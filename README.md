# gabryelboeira.github.io

Site pessoal e portfólio profissional de **Gabryel J Boeira** — Desenvolvedor Back-End Java.

## Acesse

[https://gabryelboeira.github.io](https://gabryelboeira.github.io)

## Sobre

Site estático hospedado no GitHub Pages com foco em apresentar experiência profissional, habilidades técnicas, formação acadêmica, certificações e projetos open source.

## Tecnologias

- HTML5 semântico
- CSS3 customizado (sem frameworks)
- JavaScript vanilla
- GitHub Pages (hospedagem)
- API do GitHub (listagem de repositórios em tempo real)

## SEO e Indexação

- Meta tags Open Graph e Twitter Cards
- JSON-LD (Schema.org `Person`)
- Sitemap XML
- robots.txt com permissões para crawlers de IA
- Google Search Console verificado

## Estrutura

```
├── index.html          # Página principal
├── css/style.css       # Estilos
├── js/main.js          # Navegação e interações
├── js/gitCardRepo.js   # Cards de repositórios via API GitHub
├── img/                # Imagens
├── robots.txt          # Regras para crawlers
├── sitemap.xml         # Mapa do site
└── _config.yml         # Configuração Jekyll/GitHub Pages
```
